# Skill Card: 门店陈列合规巡检 (`planogram-compliance`)

## Description

Check a shelf photo of store bay A12 against the store's planogram and SKU master, and report each planned SKU as OK, LOW or OOS plus any MISPLACED SKU, using the store's SKU codes.

Proven workflow: A store auditor photographed bay A12; the agent identified SKUs with the store SKU master, counted front-row facings per shelf, compared them with the bay A12 planogram using the store's min-facing policy, and produced a per-SKU compliance list the replenishment team could act on.

## Use Case

Use when:
- 检查货架照片是否符合陈列图 / planogram
- 巡检 A12 货架的陈列合规、缺货和错放
- 按门店 SKU 编码输出每个商品的陈列状态
- check a shelf photo against the planogram

Not for:
- 只统计货架排面或空位，不对照陈列图
- 根据库存数据库生成补货单但没有图片
- 撰写商品营销或促销文案
- 识别顾客身份或人口属性

## Known Risks and Mitigations

- Risk: Model misreads the input (miscounts, misidentifies items).
  Mitigation: Outputs are scored against ground truth before release (see Release Evidence); uncertain observations must be listed in `uncertainties` for human review.
- Risk: Inputs leave the device.
  Mitigation: The runner's destination is fixed to 127.0.0.1; it reads no environment variables and handles no credentials.
- Risk: Skill files are modified after review.
  Mitigation: The directory is signed as `skill.oms.sig`; verify it before installation with `model_signing verify certificate planogram-compliance --signature planogram-compliance/skill.oms.sig --certificate_chain <root-cert.pem>`.
- Risk: Skill loads for requests it should not handle.
  Mitigation: Negative trigger boundaries are in the description and were evaluated with repeated agent runs.
- Risk: Workflow guardrail
  Mitigation: 只依据图片中可见的排面，不推断画外或遮挡后的库存。
- Risk: Workflow guardrail
  Mitigation: sku_code 只能来自 SKU 主数据；陈列图和政策只来自技能附带的参考资料。
- Risk: Workflow guardrail
  Mitigation: 不得识别或推断顾客身份、年龄、性别或行为意图。
- Risk: Workflow guardrail
  Mitigation: 不得输出输入图片的 base64 数据或任何运行时凭据。
