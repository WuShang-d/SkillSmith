# SkillSmith 参赛包装

技术内容不变，换讲法：**先讲一个人、一家店、一次成功，再讲门禁**。所有物料（作品说明、路演、视频）都按下面这条主线讲，数字全部来自 `evidence/dgx-2026-09-23/` 与 `evidence/dgx-2026-09-24/release/`。

## 一句话

> **把 Agent 的一次成功，锻造成全公司都敢装的能力。**

展开版：SkillSmith 在 DGX Spark 本地，把一次跑通的多模态工作流生成 Agent Skill，再用安全扫描、公平 A/B、真实触发和签名决定它能不能上线——没用的拦下，有用的签名发布。

### 金句（路演和问答里反复用）

- **安全，不等于有用。**
- **它安全、好找，但没用——所以不装。**
- **Skill 不光要赢过不装，还要赢过把资料直接贴进去。**
- **那条误报是我们自己说出来的。**
- **一次做对是运气，每次都对才是能力。**

### 三个创新点（评委问"你们和别人有什么不同"时）

1. **会说"不"的发布门禁。** 大多数作品证明自己的 Skill 有用；我们在现场展示门禁拦下一个"看起来完美"的 Skill。
2. **"粘贴资料"对照组。** 带业务资料的 Skill 必须赢过"把同样资料贴进提示词"，否则提升不算 Skill 的功劳——这是我们在自己第一版数据作废后加上的。
3. **企业自研 Skill 的本地信任链。** 对齐 NVIDIA Verified Skills（Scanned · Evaluated · Signed · Documented），但全部在一台 DGX Spark 上完成：SkillSpector 扫描、Skill Card、OpenSSF 签名、验签安装，业务图片和陈列图不出机器。

## 作品说明（约 500 字）

> **SkillSmith：把 Agent 的一次成功，锻造成全公司都敢装的能力**
>
> 同事用 Agent 跑通了一次门店货架检查，大家就把提示词打包成 Skill，准备推给所有门店。可没人答得上来：装上它，Agent 真的更好吗？该用时会用、不该用时不乱用吗？装进门店的是不是发出去的那一版？货架照片和陈列图能不能不出本地？
>
> SkillSmith 在 NVIDIA DGX Spark 上，10 分钟内把一次成功的多模态工作流生成标准 Agent Skill，再送进一道发布门禁：NVIDIA SkillSpector 安全扫描；同模型公平 A/B（对照组拿到相同输出格式、按真值打分，带资料的 Skill 还必须赢过"直接粘贴资料"）；OpenClaw 真实触发测试；OpenSSF 签名与验签安装。任何一关不过，就不安装。
>
> 在本地 Qwen3.6-35B-A3B 上实测：货架巡检 Skill 安全、触发 36/36 全对，但得分 82.7% 对 82.3%，没有更好，被门禁拦下；陈列合规 Skill 从 11.1% 提升到 78.4%，赢过粘贴资料的 72.6%，还快约 5 秒，签名发布。在从未参与评测的新照片上找出全部 3 个真实偏差，1 条误报如实披露；篡改一个词，验签失败、拒绝安装。
>
> 推理、评测与签名全部在本地完成。零售只是示例，任何跑通过一次的 Agent 流程都能走这道门。

## 问答准备

**Q：这不就是一个测试框架吗，Agent 在哪？**
SkillSmith 本身就是一个 Skill（`skills-src/skillsmith/`），Agent 装上它就能自己把一次成功沉淀成新 Skill 并走门禁；生成出来的 Skill 也在 OpenClaw 里被真实 Agent 触发和使用。它是"Agent 给自己长能力"的那一环。

**Q：82.7 对 82.3 差这么点，拦下是不是太严？**
门禁要求严格优于基线。一个 Skill 不带来提升，却要占用每个 Agent 的上下文、增加误触发风险，就不该推给所有门店。彩排里它是 82.7 对 82.7 持平，同样被拦。

**Q：测试图是合成的，能代表真实门店吗？**
合成是为了得到精确真值：每个排面由脚本放置，打分可复现。换成真实门店照片只需要换评测集，门禁逻辑不变；我们不把合成图说成真实数据。

**Q：为什么一定要在 DGX Spark 上？**
陈列图、SKU 表和门店照片是商业数据；35B 多模态模型、上百次 A/B 与触发评测、签名都在一台机器上跑完，一次完整门禁约 3 分钟（不含 OpenClaw 触发，约 70 秒/次）。

**Q：你们自己第一版数据为什么作废？**
第一版基线不知道输出格式，评分又只查字段名，得到 23.6% → 100% 的"提升"。我们发现后改成公平对照和真值评分，并保留了作废记录——这正是 SkillSmith 要帮别人避免的坑。
